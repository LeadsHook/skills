LeadsHook for AI agents

Build, edit, and publish LeadsHook decision trees and landing pages by chatting with your AI agent, connected to your own LeadsHook account.

Claude Code

Run these two commands inside Claude Code:

/plugin marketplace add LeadsHook/skills
/plugin install leadshook@leadshook

Then restart Claude Code, or run /reload-plugins.

Any other agent

Point your agent at the setup instructions and let it follow them:

Read https://leadshook.github.io/skills/prompt.md and follow it.

The page covers Claude Code, Codex, Cursor, Copilot, and Windsurf, plus verification and troubleshooting.
